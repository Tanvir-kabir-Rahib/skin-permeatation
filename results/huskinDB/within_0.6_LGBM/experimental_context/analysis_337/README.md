# LGBM ±0.6: analysis of 337 selected HuSkinDB measurements

This directory contains a measurement-level analysis of the 337 rows for which
the absolute LGBM prediction error is at most 0.6 log10(cm/s).

The selection depends on the experimental outcome, so these files describe the
selected subset and must not be treated as an unbiased validation cohort.

Primary outputs are generated by `lgbm_337_experimental_context_analysis.ipynb`:

- `lgbm_337_rows_annotated.csv`: all 337 original rows plus compound-, reference-,
  condition-, and completeness-level annotations.
- `lgbm_337_condition_profile.csv`: reported-value coverage for the 14 condition fields.
- `lgbm_337_reference_summary.csv`: measurement and compound coverage by citation.
- `lgbm_337_compound_variability.csv`: selected-subset logKp variability by compound.
- `lgbm_337_same_reference_series.csv`: repeated compound/reference series.
- `lgbm_337_variability_extremes.csv`: minimum-versus-maximum experimental rows for
  each repeatedly measured compound, including the condition fields that differ.

Sentinel values such as `unknown`, `N/A`, and `not reported` are treated as unavailable.
